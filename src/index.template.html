A small laboratory for spacetime

One diagram. Many observers.

Two geometries

The Geometry selector switches between Minkowski spacetime (x, t) and a Euclidean plane (x, y). Each mode keeps its own scene, including custom drawings. Undo can also undo a switch. Save scene and Save HTML include both scenes. Choosing an example replaces the current mode’s scene.

Euclidean coordinates rotate by θ: x = x₀ cos θ + y₀ sin θ, y = y₀ cos θ − x₀ sin θ. Positive θ rotates the viewing axes counterclockwise relative to the reference axes; fixed objects rotate clockwise on screen. Lengths and angles remain invariant. The slider uses degrees or radians; it spans −180° to +180°. There is no time coordinate, light cone, speed or Lorentz factor in this mode.

Euclidean examples compare vector components with time dilation, oblique strip widths with length measurements, a straight path and a detour with the twins, and a tilted pole with the barn. They are comparisons of geometry, not Euclidean versions of relativistic physics. Each example explains where the analogy ends.

Coordinates and boosts — Minkowski

We use c = 1 and metric s² = Δt² − Δx². A unit of time and a unit of distance have the same scale on screen (for example, years and light-years). The vertical and horizontal display coordinates are always t and x. The stored reference coordinates are t₀ and x₀. Positive v means that the viewing observer moves to the right relative to the reference frame: t = γ(t₀ − vx₀), x = γ(x₀ − vt₀). Rapidity η = atanh v; γ = cosh η. The controls set an absolute boost relative to the reference frame, not a succession of accumulated boosts.

The faint display grid and t / x guides belong to the current view. In the time-dilation example, the paired hyperbolae calibrate time and space axes at four units: t² − x² = 16 and x² − t² = 16. The coloured frame axes are actual editable objects: they transform, can be hidden or deleted, and have ticks calibrated in that frame’s units. “Add this frame’s axes” captures the current observer’s origin-sharing inertial frame. Changing the view does not change the physical experiment.

Draw and edit

Select a tool, then drag to draw a segment, infinite line, arrow, rectangle, circle or freehand curve. Click for an event or a text label. A hyperbola is set by clicking a point on its locus: t² − x² determines its kind and scale. Full origin-centred hyperbolae are invariant under these boosts. Their geometric locus stays fixed, while individual events on it transform. A translated hyperbola’s centre transforms with the diagram. In Euclidean mode, the circle tool replaces the invariant hyperbola: drag from its centre to a point on its circumference. Its radius is invariant under rotation; an origin-centred circle stays fixed, while an offset centre rotates. In Minkowski mode, choose Light cone and click to set the vertex. Both past and future null rays are created as one editable object; drag it or edit its centre to move the vertex.

Use Select to pick and drag objects, or select them in the object list. Drag endpoint handles to reshape segments, arrows, lines and polygons. Edit precise coordinates, text, colour and line style in the Inspector. Colour buttons open a palette of KTH and diagram colours. Select a swatch to apply it, or expand “Custom colour” for a free choice. A palette colour can be applied to several selected objects at once. Label offsets are preferred positions; labels may shift slightly to avoid overlap. Coordinates there are in the current viewing frame. Select several objects with Shift + click. Toggle an object’s checkbox to hide it.

Go to a selected line’s frame

In Euclidean mode, Space aligns the selected line vertically by a smooth rotation; the Inspector also offers “Align horizontally”. For a saved frame axis, Space restores its captured frame. This is spatial alignment, not an observer at rest.

Select one straight line, segment, arrow or frame axis. For a timelike direction, “Go to rest frame” makes it vertical (Δx = 0): it describes an observer at a constant position. For a spacelike direction, “Make purely spatial” makes it horizontal (Δt = 0): its events are simultaneous. The boost is computed from the line’s reference-coordinate direction, so it also works when you are already viewing a boosted frame. Lightlike lines have no such finite inertial frame; a zero-length segment has no direction.

Frame actions and the example’s frame shortcuts animate smoothly in rapidity in Minkowski mode, and in angle in Euclidean mode. Press Esc or use another control to interrupt. A transition is a single undo step. Reduced-motion system preferences are respected. The slider range expands if the chosen frame requires |v| > 0.98.

Full-screen workspace

Choose “Full screen” to give the diagram the main canvas and place the boost slider vertically on the right. Positive velocity, rapidity or rotation angle is at the top; negative is at the bottom. “Drawing tools” opens the drawing and colour controls. “Objects” opens the object list and Inspector over the diagram, so geometry and text remain editable. Use “Exit” or Esc to return to the regular layout. Where browser fullscreen is unavailable, the same layout fills the app’s available window.

Euclidean rotation arrows wrap at ±180° (±π radians), so you can keep turning in either direction. Minkowski boost arrows stay within the slider’s current range. With the slider focused, ↑ / ↓ also change the boost and Home / End select its minimum / maximum. Space now changes frame; use H for panning.

Navigation and files

Fit includes the defining points of visible objects; infinite curves have no finite bounding box. The ⌂ button restores the example’s initial camera.

Save scene downloads editable JSON. Open scene restores it. Save HTML downloads this complete application with the current scene embedded: send that one file to a colleague or open it offline. Export SVG saves the current diagram as vector artwork. Changes are also kept locally in this browser when browser storage is available; use a downloaded file for reliable storage. Loading another example replaces the current scene and can be undone.

Teaching examples

The example speeds and physical lengths are fixed; the observer slider changes the coordinate description. The twin’s turn is instantaneous, and the pole-in-barn example uses ideal, momentary door closures without stopping the pole. All four Minkowski and four Euclidean examples, blank canvases, and explanatory notes are bundled in this file.
